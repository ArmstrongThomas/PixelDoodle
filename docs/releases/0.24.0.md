# Pixel Doodle 0.24.0

Pixel Doodle is an offline pixel-art editor for Nintendo DS, DSi and 3DS.
This is the first public release, so it includes the complete editor and
animation toolset.

## Canvas and drawing

- Canvases from 1 to 128 pixels per side on DS, and up to 512 pixels per side
  on DSi and 3DS. New projects offer 16, 32, 64, 128, 256 and 512 pixel
  presets on DSi and 3DS, plus custom width and height.
- Up to eight layers and up to 256 frames per project. The new-project screen
  shows the layer capacity for the chosen canvas, and the timeline shows the
  frame-memory budget in use.
- Pencil and eraser with 1-16 pixel size, square or round tips, four saved brush
  presets, and a pixel-perfect mode for the one-pixel pencil.
- Pencil, fill and shape dithering at Solid, 25%, 50% or 75% coverage.
- Fill tool with contiguous-region or global colour replacement, active-layer
  or visible-image matching, and 0-255 tolerance.
- Line, rectangle and ellipse tools with outline or filled interiors, shared
  brush size, dithering, live preview and one undo step per shape.
- Colour sampling from the visible artwork.
- Undo and redo with 32 transactions in a 512 KiB history. Paint history is
  frame-aware, so undo follows artwork across frames.

## Selections and transforms

- Rectangle and freehand lasso selections.
- Replace, add and subtract selection modes.
- Move, cut, copy, paste and delete selected pixels, plus Select All and
  Deselect.
- Flip horizontally, flip vertically and rotate 90 degrees clockwise.
- Duplicate the selection to a new layer.
- Scale the selection 2x, 3x or 4x, or to half size, preserving alpha and
  selection holes.

## Colour

- RGBA colour with separate foreground and background targets and one-tap swap.
- Square saturation/value picker, vertical hue rail and alpha control.
- RGB, hex and alpha numeric entry.
- Recent colours and a scrollable quick palette.
- Palettes from 1 to 256 colours with an adjustable swatch grid.
- Add, replace, remove and reorder swatches.
- Built-in default palette and a user-saved default palette.
- Import and export GPL, HEX and PNG-strip palettes.
- Project palettes are stored in native projects and Aseprite files.

## Layers

- Add, delete, duplicate, rename and reorder layers.
- Per-layer visibility, lock, alpha lock and opacity.
- Normal, Multiply, Screen and Overlay blend modes.
- Merge down for normal-blend layers.
- Composite and active-layer previews on the upper screen, including a marker
  when the active layer is hidden.

## Animation

- Up to 256 frames with per-frame durations from 10 to 60,000 ms.
- Add, duplicate, delete and reorder frames.
- Layers and Timeline tabs with a frame grid, tag band, memory meter and
  frame strip.
- Playback uses each frame's own duration. It loops the innermost tag containing
  the current frame, or the whole animation when no tag applies.
- Named tags with inclusive frame ranges, six colours and forward, reverse,
  ping-pong or pong-ping playback.
- Linked cels: link a cel with the previous frame, unlink it, or add a new
  linked frame. Editing any member of the group updates the whole group.
- Onion skin with 1-3 previous and next frames, 10-90% opacity and an optional
  red/blue tint.
- Frame sheet with duration presets, fine adjustment, apply-to-one or
  apply-to-all, move left/right, delete and tag editing.
- Timeline moves: hold L and tap frame numbers to mark whole frame columns, then
  hold a marked number and drag the block to a new position. A single frame
  moves the same way without marks. Hold a cel and drag it to another layer,
  frame, or both.
- Canvas frame strip for scrubbing, stepping, play/pause and the onion toggle.
- Upper-screen animation view with the current frame, frame details and a
  filmstrip.

## Guides

- Pixel grid, shown from 4x zoom upward.
- Independent horizontal and vertical symmetry.
- Independent horizontal and vertical tiling, with repeated wrapped drawing and
  fill support.

## Files and storage

- Native `.pdd` projects preserving layers, frames, tags, linked cels and
  palettes.
- Open, Save and Save As, with eight recent projects.
- File browser with folders, type filtering, previews, rename, duplicate and
  confirmed deletion.
- Aseprite import and export for `.aseprite` and `.ase` files, including up to
  256 frames, up to eight flat layers, raw or zlib cels, RGBA pixels, layer
  order/visibility/opacity, Normal/Multiply/Screen/Overlay blending, per-frame
  durations, tags with colours and linked cels.
- PNG artwork import as a single RGBA layer, including RGB, RGBA, grayscale,
  grayscale-alpha and indexed PNGs with transparency.
- PNG export of the visible composite with alpha.
- Recovery snapshots, temporary-file verification and backup copies when
  saving.
- On-screen lowercase, uppercase and symbol keyboard with cursor movement and
  hold-to-delete.

## Interface and settings

- Dual-screen layout with drawing and controls on the touch screen and
  overview, layer or animation context on the upper screen.
- Tool rail with Pencil, Eraser, Sample, Fill, Select, Line, Rectangle, Ellipse
  and Guides, each with a compact options panel.
- Touch panning, integer zoom from 1x to 32x, button shortcuts and 3DS Circle
  Pad panning.
- Remappable Tools, Pan, Sample and Zoom bindings. L/R, START and SELECT remain
  fixed.
- Adjustable toolbox and zoom-overlay side, drawing timing display, diagnostics
  with memory and card-speed tests, and a built-in controls/help reference.
- Settings, palettes, brush presets and recent files persist between sessions.

## Install

- **3DSX:** copy `PixelDoodle.3dsx` to the SD card and launch it with the
  Homebrew Launcher.
- **CIA:** install `PixelDoodle.cia` with FBI or another title installer.
- **NDS/DSi:** copy `PixelDoodle.nds` to the flashcart and launch it from the
  loader.

## Current limits

- DS mode supports canvases up to 128 pixels per side. DSi and 3DS support up
  to 512.
- Up to eight layers and 256 frames, but the largest canvases reduce layer
  capacity and all frames share a fixed memory budget.
- Selection scaling and clipboard transforms are limited to selections up to
  128x128 pixels.
- Undo keeps 32 transactions within a 512 KiB budget.
